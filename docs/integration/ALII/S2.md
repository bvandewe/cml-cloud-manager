# ALII: S2

HTTP Method: `GET /labInstance/{labInstanceId}`

**Input**

- Path parameter: `labInstanceId` (string, required)

**Output**

**Sample Response - Success**

```json
{
  "labInstanceId": "1234",
  "url": "https://labtesting.com/laburl?id=1234",
  "status": "INITIALIZED",
  "custom": [
    {
      "name": "userName",
      "value": "ALII_user"
    },
    {
      "name": "password",
      "value": "ALII_Pwd"
    }
  ]
}
```

**Sample Response - Pending with wait time**

```json
{
  "labInstanceId": "1234",
  "url": "https://labtesting.com/laburl?id=1234",
  "status": "PENDING_INITIALIZATION",
  "waitTime": 60
}
```

**Sample Response - Failure**

```json
{
  "status": "ERROR",
  "errorCode": "​INVALID_LAB_ID​",
  "errorMessage": "Invalid lab identifier"
}
```

**Error Codes**

| Code | HTTP Status | Description |
|---|---|---|
| INVALID_LAB_ID | 400 | Invalid lab identifier |
| INVALID_IP_FORMAT | 400 | Invalid ip address format |
| INVALID_COUNTRY_CODE | 400 | Invalid country code |
| INVALID_CLIENT_ID | 400 | Invalid client identifier |
| INVALID_CANDIDATE_ID | 400 | Invalid candidate identifier |
| INVALID_REG_ID | 400 | Invalid registration identifier |
| SYSTEM_ERROR | 500 | Unexpected system error.  Eligible for auto recovery. |
