# ALII: S1 Initialize Lab Item

HTTP Method: `POST /labInstance`

**Input**

```json
{
  "clientId": "clientCode",
  "labId": "1001",
  "candidateId": "Cand1325376800",
  "registrationId": "2325376900",
  "ipAddress": "69.89.31.226",
  "country": "USA"
}
```

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "clientId": {
      "type": "string",
      "example": "clientCode"
    },
    "labId": {
      "type": "string",
      "example": "1001"
    },
    "candidateId": {
      "type": "string",
      "example": "Cand1325376800"
    },
    "registrationId": {
      "type": "string",
      "example": "2325376900"
    },
    "ipAddress": {
      "type": "string",
      "format": "ipv4",
      "example": "69.89.31.226"
    },
    "country": {
      "type": "string",
      "example": "USA"
    }
  },
  "required": [
    "clientId",
    "labId",
    "candidateId",
    "registrationId",
    "ipAddress",
    "country"
  ],
  "additionalProperties": false
}
```

**Output**

**Sample Response - Success**

```json
{
  "labInstanceId": "1234",
  "url": "https://labtesting.com/laburl?id=1234",
  "status": "INITIALIZED",
  "custom": [
    {
      "name": "userName",
      "value": "ALII_user"
    },
    {
      "name": "password",
      "value": "ALII_Pwd"
    }
  ]
}
```

**Sample Response - Pending with wait time**

```json
{
  "labInstanceId": "1234",
  "url": "https://labtesting.com/laburl?id=1234",
  "status": "PENDING_INITIALIZATION",
  "waitTime": 60
}
```

**Sample Response - Failure**

```json
{
  "status": "ERROR",
  "errorCode": "​INVALID_LAB_ID​",
  "errorMessage": "Invalid lab identifier"
}
```

**Error Codes**

| Code | HTTP Status | Description |
|---|---|---|
| INVALID_LAB_ID | 400 | Invalid lab identifier |
| INVALID_IP_FORMAT | 400 | Invalid ip address format |
| INVALID_COUNTRY_CODE | 400 | Invalid country code |
| INVALID_CLIENT_ID | 400 | Invalid client identifier |
| INVALID_CANDIDATE_ID | 400 | Invalid candidate identifier |
